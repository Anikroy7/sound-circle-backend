# bangladesh-geo-data

`city_corporations.json`, `thanas.json` and `districts.json`, copied unmodified from the npm package
[`bangladesh-geo-data`](https://www.npmjs.com/package/bangladesh-geo-data) **4.0.9** (`dist/data/`).

License: MIT © Shodorson.

`location.seeder.ts` reads the 12 city corporations and the 110 metropolitan thanas from here. The divisions,
districts and upazilas come from the BBS-coded files one folder up; `districts.json` is only used to match this
package's district ids to those by name.
